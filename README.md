# Personal Portfolio - Sujay Paul

A clean, responsive personal portfolio website built with semantic HTML, CSS, and Vanilla JavaScript. Developed as part of the **ShadowFox Frontend Web Development Internship**.

## Overview

This portfolio showcases my background, technical skillset, and frontend projects. It is lightweight, fully responsive across devices, and built without heavy frameworks to focus on core web fundamentals.

## Key Features

- **Responsive Navigation**: Mobile-friendly hamburger menu with smooth section scrolling.
- **About & Skills**: Clean breakdown of technical skills across frontend development, styling, and tools.
- **Featured Projects**: Showcase cards linking directly to GitHub project repositories.
- **Contact Form Validation**: Client-side form checking for valid email formats and required inputs with clear status messages.
- **Modern UI**: Custom typography, cohesive color palette, and subtle hover interactions.

## Tech Stack

- **Structure**: Semantic HTML5
- **Styling**: CSS3 (CSS Variables, Flexbox, CSS Grid, Media Queries)
- **Logic**: Vanilla JavaScript (ES6+)
- **Icons**: Font Awesome 6

## Project Structure

```text
├── Assets/          # Images and profile photos
├── css/
│   └── style.css    # Main stylesheet & responsive rules
├── js/
│   └── main.js      # Mobile menu toggle & form validation logic
├── index.html       # Portfolio homepage
└── README.md        # Project documentation
```

## Getting Started

No build steps or package installations are needed:

1. Clone the repository:
   ```bash
   git clone https://github.com/EL-STRIX/ShadowFox_Personal_Portfolio.git
   ```
2. Open `index.html` in your web browser (or use VS Code's Live Server extension).
